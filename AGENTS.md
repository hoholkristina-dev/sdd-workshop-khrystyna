# AGENTS.md

Короткий контекст для бізнес-аналітика, який працює з цим репозиторієм і з агентом у Cursor.

## Проєкт

Це навчальна копія клієнтського сайту Фонду Лятошинського: публічний Next.js-застосунок про композитора Бориса Лятошинського, діяльність фонду, архів, наукові роботи, новини, партнерство та підтримку. Контент двомовний (українська й англійська), дані для сторінок беруться з демо-наповнення в пам’яті, а не з бойової бази. Оригінальний продукт: [lf-client](https://github.com/Liatoshynsky-Foundation/lf-client). Локально сайт відкривається на `http://localhost:3000` після `npm run dev`.

Публічні маршрути мають префікс мови: `/uk/...` і `/en/...`. Мова за замовчуванням — `uk`.

## Основні сторінки

| Маршрут | Бізнес-призначення |
| --- | --- |
| `/` | Перенаправляє на мовну версію `/uk` або `/en`. Головну сторінку відображає `app/[lang]/page.tsx`: перше знайомство з композитором і фондом, події, творчість, новини, співпраця |
| `/about-us` | Про фонд: місія, цілі, напрями роботи, засновники, кабінет Лятошинського |
| `/biography` | Біографія Бориса Лятошинського |
| `/artistry` | Каталог музичних творів із пошуком і відтворенням |
| `/research` | Наукові роботи: перелік, фільтри, назви |
| `/archive` | Архів: перелік фондів |
| `/archive/{fund}` | Документи обраного фонду |
| `/archive/{fund}/{case}` | Картка архівної справи |
| `/news` | Медіацентр: згадки та матеріали про фонд |
| `/cooperation` | Співпраця: формати партнерства, партнери, пропозиція співпраці |
| `/support-us` | Підтримка фонду: способи допомоги, донат, відповіді на часті питання |
| `/war-in-ukraine` | Ініціативи фонду, пов’язані з війною в Україні, і волонтерська підтримка |
| `/contacts` | Контакти фонду та соцмережі |
| `/privacy-policy` | Політика конфіденційності |
| `/terms` | Умови користування сайтом |

Службова сторінка `/api-docs` показує опис API і не є частиною публічного сценарію для відвідувача.

## Конвенції

- Код пишемо на TypeScript.
- Файли сторінок Next.js (`page.tsx`) використовують default export. Для інших модулів рекомендується іменований експорт.
- Українська (`uk`) — основна мова інтерфейсу і текстів. Англійська (`en`) — друга локаль. Новий копірайт спочатку описуємо українською.

## Навчальний репозиторій

Це шаблон для воркшопу spec-driven BA, а не бойове середовище. Окрема MongoDB не потрібна: під час кожного запуску створюється база в пам’яті й наповнюється демо-даними. Після зупинки застосунку база зникає, тож будь-які зміни даних не зберігаються між запусками.
